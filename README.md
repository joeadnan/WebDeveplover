# TokoKita - E-Commerce Web Platform (Modular Vanilla JS)

Platform e-commerce berkinerja tinggi berbasis **Vanilla JavaScript (ES6+)**, **HTML5**, dan **CSS3** dengan struktur berkas terpisah (*Zero External Frameworks*).

## Struktur Project
```
tokokita-ecommerce-v2/
├── index.html        # Struktur markup HTML
├── style.css         # Berkas styling CSS3 dengan CSS Variables
├── app.js            # Logika SPA Router, State Management & Event Handling
└── README.md         # Dokumentasi petunjuk penggunaan
```

## Fitur Utama
1. **Struktur Modular**: HTML, CSS, dan JS dipisah secara rapi untuk mempermudah kustomisasi.
2. **Zero External Frameworks**: 100% murni Vanilla JS ES6+.
3. **SPA Router**: Navigasi halaman cepat tanpa *hard reload*.
4. **State Management & LocalStorage**: Retensi keranjang belanja tersimpan otomatis di browser.
5. **Memory Leak Prevention**: Pembersihan *Event Listener* otomatis saat perpindahan halaman.
6. **Validasi Regex Real-time**: Form checkout interaktif.

## Cara Menggunakan
1. Extract file zip `tokokita-ecommerce-v2.zip`.
2. Buka folder `tokokita-ecommerce-v2/` di kode editor pilihan Anda.
3. Jalankan `index.html` langsung di browser atau menggunakan Live Server.
